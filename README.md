# Bit-Bite

매일 한입(Bite), CS 지식(Bit)을 설명하는 습관: 개발자 및 취준생을 위한 AI 기반 CS 설명 훈련 서비스


## ✨Main 기능
- 이메일 인증 및 분야 선택을 통한 서비스 구독
- 매일 정해진 시간마다 AI를 통한 질문 생성
- 매일 정해진 시간마다 선택한 분야에 해당하는 질문 메일 발송
- 사이트 접속해 질문에 답변을 제출하면 AI를 통해 생성한 제공
